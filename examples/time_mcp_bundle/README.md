# Time MCP Bundle

Kleines Referenz-Bundle fuer den MCP-Installer.

Eigenschaften:

- `mcp.json` als Zielbild-Manifest
- `stdio` Transport
- per-MCP `.venv` als Runtime-Ziel
- host-managed Icon, Launchpad und generische Settings

Das Bundle kann direkt als Archiv gepackt und ueber den MCP-Installer hochgeladen werden.
