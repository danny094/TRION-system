# Self Context

Kleine Contract-Schicht fuer `SelfContext v1`.

Zweck:

- vorhandene Policy-, Runtime-, Tool- und Memory-Signale zu einer
  verifizierten Selbstsicht zusammenfassen
- keine neue Persistenz
- keine MCP-Sonderregeln

Version 1 liefert nur:

- `identity`
- `current_scope`
- `capabilities`
- `memory_visibility`
- `uncertainties`
